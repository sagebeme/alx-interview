0x06. Star Wars API
===================

This project uses the **Star Wars API (SWAPI)** to fetch and print characters that appear in a given film (by film ID). You practice HTTP requests and parsing JSON.

Tasks
-----

### 0. Star Wars characters

mandatory

Take a film ID as argument (e.g. `python3 0-starwars_characters.py 1`), request the film and character URLs from SWAPI, and print character names that appear in that film. Run: `python3 0-starwars_characters.py <film_id>`.

**Repo:**

-   GitHub repository: `alx-interview`
-   Directory: `0x06-starwars_api`
-   File: (main script)

---

**How to run / test**

1. Install `requests`: `pip install requests`.
2. Run with a valid film ID (e.g. 1 for "A New Hope") and verify character names.
