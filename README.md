# ALX Interview preparation

This repository contains **interview preparation** tasks: algorithms and coding challenges (Pascal's triangle, lockboxes, minimum operations, log parsing, UTF-8 validation, N-queens, Star Wars API, rotate 2D matrix, making change, island perimeter, prime game). Each folder is one task; this README explains what each folder is for, what the main files do, and how to run the exercises.
